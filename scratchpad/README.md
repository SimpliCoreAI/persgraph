# Scratchpad Workflow

Use this folder for transient shared thinking between models.

## Purpose
- Temporary working memory for one active topic
- Handoff space between Claude/Sonnet, GPT, and Haiku
- Not a durable knowledge base
- Never promote raw scratch content into `MEMORY.md` automatically

## Lifecycle
- `active/` = current live topic
- `handoff/` = notes for another model to continue
- `closed/` = finished topics that may be archived or deleted

## Suggested note format
Each scratchpad note should include:
- Goal
- Current context
- Decisions made
- Open questions
- Next actions
- Model handoff notes
- Completion criteria

## Rules
- Keep notes short and actionable
- One topic per file
- Include dates/timestamps when useful
- Remove or close files when the topic is done
- Do not store secrets, tokens, or public-facing credentials here
