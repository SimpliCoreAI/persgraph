HOW IT WORKS
================================================================================

OpenClaw Cron (hourly)
  ↓
explore_deliver_suggestions.py
  ↓
check_once() from explore_mode.py
  ↓
Should suggest?
  ├─ YES → Generate suggestion → Print to stdout → Telegram delivery
  └─ NO  → Skip check → Print nothing → No spam

Key Design:
- Cadence-aware: respects session's cadence (default 60 min)
- Expiry-aware: auto-disables expired sessions
- Location-aware: checks movement since last suggestion
- State-aware: reads/updates explore_state.json atomically
- Error-resilient: catches exceptions gracefully

SETUP INSTRUCTIONS FOR NEXT STEP
================================================================================

The OpenClaw cron job needs to be created by the gateway admin.
Run this command:

  openclaw cron add \
    --name "Explore Mode Delivery" \
    --cron "0 * * * *" \
    --to "telegram:8596241969" \
    --announce \
    --timeout-seconds 30 \
    --model "litellm/fast" \
    --message "cd /root/AgenticHub/Persgraph && PYTHONPATH=. .venv/bin/python agents/explore-delivery/explore_deliver_suggestions.py"

After creation:
1. Verify: openclaw cron list | grep "Explore Mode"
2. Test: openclaw cron run "Explore Mode Delivery"
3. Enable Explore Mode: /TripToggle On 2h 60m medium
4. Wait for next hourly run (~60 minutes)
